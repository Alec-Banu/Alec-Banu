Weekly Payroll Calculator

A C# console app that calculates weekly payroll with regular, overtime, and double overtime pay.

Overview

This program calculates weekly payroll for 7 employees stored in parallel arrays. It handles three pay tiers — regular, overtime, and double overtime — with full input validation and a detailed payroll report output.

Features

  • Regular, overtime (1.55x) and double overtime (2.2x) pay calculation
  • Input validation for hours worked and hourly rate
  • Parallel arrays as data repositories
  • Unit tested with automated test suite
  • Clean payroll report output

Built With

  • C#
  • .NET 8
  • Parallel Arrays
  • Unit Testing
