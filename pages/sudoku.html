Sudoku

A console-based Sudoku game built in C# supporting 4x4 and 9x9 grids.

View Code

Overview

This project is a single-player console Sudoku game written in C#. Players can choose between a 4x4 or 9x9 grid, fill in cells using Excel-style position input (e.g. A1, B3), and save the completed board to a text file.

Features

  • 4x4 and 9x9 board sizes
  • Excel-style position input (A1, B2, etc.)
  • Input validation and error handling
  • Save completed board to a text file
  • Randomly generated boards using 2D arrays

Built With

  • C#
  • .NET 8
  • 2D Arrays
  • File I/O
